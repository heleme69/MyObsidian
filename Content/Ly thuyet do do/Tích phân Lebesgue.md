> [!def] (Simple function)
> Given a measure space $(X, \mathfrak{A}, \mu)$. A function $\varphi$ is called a simple function if it satisfies the following conditions: 
> (i) $\mathfrak{D}(\varphi) \in \mathfrak{A}$,
> (ii) $\varphi$ is $\mathfrak{A}$-measureable on $\mathfrak{D}(\varphi)$,
> (iii) $\varphi$ assumes only finitely many real vaules, that is, $\mathfrak{R}(\varphi)$ is a finite subsest of $\mathbb{R}$.
> (Note that $\mu(\mathfrak{D}(\varphi)) = \infty$ is permissible but $\infty$ and $-\infty$ are not permissible values for a simple function $\varphi$.)
